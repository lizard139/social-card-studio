# Social Card Studio

一个基于 Guizang Swiss Social Card 视觉系统的本地 HTML 编辑器，用 S01–S12 规范版式制作 1080 × 1440 社交卡片。

## 运行

可直接打开 `index.html`。推荐启动本地静态服务：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已实现

- Swiss International 视觉系统、4 套受控强调色，以及本地 Noto Sans SC / IBM Plex Mono 字体
- 12 个按 skill 结构编排的 3:4 Swiss 版式：S01–S12
- 右侧可视化模板图库，切换版式时生成对应的组件组合
- 新增页面时先选择模板，不再固定创建同一种封面
- 规范版式固定组件顺序与容量；修改结构会切换到保留原有自由度的自定义排版
- 自定义排版可添加、隐藏、删除、拖动组件，并按 4 / 6 / 8 / 12 列调整宽度；组件结构重新符合当前模板时自动恢复规范版式
- 逐页新增、复制、删除、排序和版式切换
- 右侧结构化字段编辑，以及画布内直接改字
- 图片上传后自动压缩，可分别设置每个图片或界面组件的素材、裁切焦点与 `cover / contain`
- localStorage 自动保存、撤销和重做
- Deck JSON 导入与下载
- 当前页或全部页面 PNG / JPG 导出，导出组件已保存在项目内，可离线使用
- 规范版式保持字号与留白，不自动缩小整张卡；检测标题行数、内容溢出、行内裁切、标题间距与下方过量留白，并阻止有问题的导出
- 规范版式中的条目标题统一使用同一字体层级；画布内编辑只写入纯文本，单行字段不会因回车或粘贴格式改变组件尺寸
- S04 需要界面截图，S08 需要主视觉图片；未上传时阻止导出占位图
- 自定义排版沿用原有自动缩放与溢出保护
- 桌面与移动端响应式工作区

## 推荐体验路径

1. 点击“新增页面”，从 12 个模板中选择内容结构。
2. 在右侧模板图库切换版式并修改文案。
3. 在“页面组件”区域选择组件并编辑文案。规范版式限制条目数量；如要自由增删或重排组件，使用“添加组件”进入自定义排版。
4. 在内容面板下方的“页面设计”区域更换主题或上传图片。
5. 点击顶部“导出图片”。
6. 下载 Deck JSON，作为可继续编辑的源文件。自定义页面可点击当前模板卡片恢复规范结构，必要时用撤销返回。

## 已知限制

- 第一版只支持小红书 3:4；1:1、21:9 和 Live Photo 尚未接入。
- Skill 的 S01–S07 提供版式原则而非逐像素尺寸；网站按其结构和视觉规则实现，并以 3:4 卡片进行排版约束。
- S08 的照片主体与文字安全区仍需人工检查；程序只检查图片是否存在和排版是否溢出。
- 编辑器不支持 Canva 式自由画布拖拽；自定义模式的拖动仅用于组件排序。
- 浏览器 localStorage 容量有限；图片会压缩，素材较多时仍应及时下载 Deck JSON。
